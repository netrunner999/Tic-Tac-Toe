***Внимание!: Данная программа является тестовой версией и разрабатывается исключительно в учебных целях.***

***Название программы: Tic-Tac-Toe (возможно будет изменено на Cyber Tic-Tac-Toe)***

***На данный момент в программе реализовано***

- Игровое поле 3x3
- Вывод результата игры (X wins or O wins or Draw)
- Возможность начать новую игру после завершения предыдущей (или прямо в процессе предыдущей игры, если например очевидна ситуация в которой итогом будет ничья)
- Разработан Cyber-дизайн для всех элементов приложения с использованием CSS-свойств
- Создан .exe файл, что упрощает загрузку и запуск программы (был проведен пробный запуск на трех разных компьютерах, на одном из которых не был установлен python)

***В будущем предполагается реализация следующих элементов***

- Игровое поле 9x9 (и соответственно возможность переключаться между полями)
- Возможность выбора игроками имен (ников) (функция уже была реализована, но из-за нескольких критических багов была временно вырезана и будет дорабатываться)
- Игра будет разделена на этапы по 5 раундов, после которых игрокам будет выведена таблица результатов за последние 5 раундов (предполагается что эти 5 раундов проводятся на одном поле одними и теми же игроками, по окончании этих 5 раундов игрокам будет предложено сменить ники и вид поля)
- Реализация меню игры в котором игроки смогут вводить свои ники и выбрать тип поля
- Реализация дополнительного режима Игрок против Бота (на поле 3x3 - точно будет разработано, на поле 9x9 - разработать сложнее (скорее всего придется применять нейронную сеть, возможно через api какой-нибудь нейронки))

***Процесс установки и запуска программы***

На главной странице проекта нажмите на зеленую кнопку Code, далее в выпадающем меню выберете Download ZIP, в результате в загрузки вашего компьютера скачается .zip архив, архив распакуйте в любой директории (рекомендуется на рабочем столе). Чтобы запустить программу перейдите в распакованную папку Tic-Tac-Toe-dev, далее папка output, далее папка main, здесь лежит исполняемый файл main.exe, запуск этого файла запустит приложение. Во время запуска .exe файла Windows может выдать ошибку "Не удается проверить издателя!", данная ошибка возникает поскольку это open-source проект, просто нажмите Ok в открывшемся окне с ошибкой.
